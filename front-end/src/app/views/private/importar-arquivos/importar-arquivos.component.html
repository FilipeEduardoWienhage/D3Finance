Formato do Arquivo

Seu arquivo CSV deve conter as seguintes colunas obrigatórias:

tipo,conta_nome,categoria,valor,data,forma,descricao

Campos Obrigatórios

📝 Campos:
  • tipo: "receita" ou "despesa"
  • conta_nome: Nome da conta (ex: "Nubank")
  • categoria: Nome da categoria
  • valor: Valor da transação
  • data: Data (AAAA-MM-DD)
  • forma: Forma de pagamento
  • descricao: Descrição (opcional)
📊 Exemplo de Linha:
receita,Nubank,Salário,5000.00,2024-01-15,PIX,Salário mensal

Exemplo Completo

tipo conta_nome categoria valor data forma descricao
receita Nubank Salário 5000.00 2024-01-15 PIX Salário mensal
despesa Nubank Alimentação 150.00 2024-01-16 Cartão de Crédito Supermercado
despesa Nubank Transporte 50.00 2024-01-17 Dinheiro Combustível

⚠️ Importante

  • • A conta deve existir no sistema antes da importação
  • • Use o nome exato da conta (ex: "Nubank", "Itaú")
  • • O arquivo deve estar em formato CSV
  • • Use vírgula como separador decimal (ex: 1500,50)
  • • A data deve estar no formato AAAA-MM-DD
